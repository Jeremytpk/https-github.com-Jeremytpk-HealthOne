# Description

HealthOne est un système de gestion hospitalière multi-tenant complet, conçu pour optimiser les opérations des établissements médicaux. Il offre une plateforme unifiée pour la gestion des soins aux patients, du personnel clinique, des inventaires médicaux et des transactions financières.

Fonctionnalités Clés
Registre et Gestion des Patients : Une base de données centralisée et sécurisée pour les profils des patients, l'enregistrement médical et le suivi des antécédents.

Coordination du Personnel par Rôles : Des tableaux de bord spécialisés pour les médecins, les infirmiers, les réceptionnistes et les administrateurs afin de gérer les effectifs et les plannings.

Contrôle Intelligent des Stocks : Un suivi en temps réel des médicaments et des équipements médicaux, avec des alertes de seuil critique et des journaux d'ajustement des stocks.

Orchestration Financière : Un système de facturation robuste pour enregistrer les paiements, suivre les revenus quotidiens et maintenir des historiques de transactions transparents.

Multi-Tenancy Sécurisé : Une isolation intégrée pour les différentes branches hospitalières, garantissant la confidentialité des données et une synchronisation cloud sécurisée.

Assistant Med-Bot : Des insights propulsés par l'IA intégrés pour aider les professionnels de santé à analyser les rapports de laboratoire et à gérer le flux des patients.

Le système est conçu avec un accent particulier sur la haute performance et la fiabilité, arborant une esthétique minimaliste « Swiss-Technical » qui privilégie la clarté et l'efficacité dans les environnements médicaux à haute pression.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
